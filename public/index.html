Roles Explained
Super Admin — Full access. Can manage all users including other admins, change any role, view audit log, and delete accounts.
Administrator — Like Super Admin but cannot view, create, modify or delete Superadmin accounts. Can manage all other users.
Manager — Can view and filter submissions and edit hours. No access to guards, sites, rates, invoices or admin management.
Viewer — Read-only access to submissions only. Cannot approve, reject or edit anything.
